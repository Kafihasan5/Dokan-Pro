# Dokan Pro — releases

Dokan Pro is a shop management app (sales, stock, due book, reports, staff) by Webix Solution.

- Buy a licence: https://webixsolution.store/dokan-pro
- Download: see [Releases](https://github.com/Kafihasan5/Dokan-Pro/releases/latest) (Android APK, Windows EXE, Mac DMG)
- Web / iPhone: https://dokanprobd.pages.dev/#app

This repository only publishes releases and `version.json` (the in-app updater reads it). The source code is private.
